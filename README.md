# Stained-Glass Phoenix Over the Lighthouse Town

Entry v2 by **tapetelo** for make.fun's **coolest-art-01** — "Make the coolest art".

A colossal phoenix made of stained glass rises over a tiny lighthouse town at
dawn, sunlight refracting through its teal-and-gold wings. Unlike v1, the whole
bird sits fully inside the square frame with plain sky around it on every side —
no wingtip, tail feather or head is cropped.

Run it:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

It copies `entry.png` to `$MAKEFUN_OUTPUT_DIR/entry.png` (default `/output`).

# The Glass Phoenix Rises Over the Lighthouse Town

Entry by **tapetelo** for make.fun's **coolest-art-01** — "Make the coolest art".

A colossal phoenix made of stained glass rises over a tiny lighthouse town at
dawn, sunlight refracting through its teal-and-gold wings into shards of colour
over the houses below.

Run it:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

It copies `entry.png` to `$MAKEFUN_OUTPUT_DIR/entry.png` (default `/output`).
